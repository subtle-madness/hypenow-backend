# FF — 발굴 자동화 (조건 기반 발굴~판정 통합)

- **소속 트랙군**: 없음 (독립 트랙)
- **의존**: [M — vertex 전환 백필 재도입](M-vertex-전환-백필-재도입.md) — 판정 LLM의 Vertex 전환이 선행 조건(무료 티어 분당 15콜로는 발굴 시점 집중 판정을 감당 못 함)
- **상태**: ⬜ 설계 완료·구현 미착수 — 설계 [specs/2026-08-29-auto-discovery-design.md](../superpowers/specs/2026-08-29-auto-discovery-design.md)

## 내용

파이프라인 중 **발굴만 수동으로 남아 있다**(`CRAWLER_SCHEDULE_DISCOVER_CRON: "-"`). 국가·산업군·팔로워 범위를 조건으로 받아 **발굴부터 산업군 판정까지 한 잡(harvest)에서 완결**하는 구조로 전환한다. 1차 목표는 우리 서비스용 일일 자동 수집이고, 사용자가 조건을 직접 등록하는 형태로의 확장을 위해 요청(조건)을 1급 개념으로 둔다 — 확장 시 바뀌는 것은 요청을 만드는 주체뿐이고 실행기·항목 큐·판정은 그대로다.

**진단(2026-08-28 실측)**: 해시태그 축은 이미 죽어 있다 — `search_keyword` 93개 중 활성 1개, `influencer_discovery` 출처가 해시태그 33건 대 suggested 2,951건으로 현 DB는 사실상 suggested 단일 축의 산물이다. 원인은 워터마크 부재로, `/v2/hashtag/medias/recent` 첫 페이지를 재호출하면 24건 중 24건이 동일하다(첫 페이지 ≈ 84분치). 축이 하나뿐이면 이미 아는 씬 안에서만 확장하는 근친교배가 된다.

**채택 설계**: 세 축(A 해시태그·검색 / B 브랜드 usertag / C suggested)을 역할을 나눠 모두 쓴다 — A·B는 시드 없이 시작하는 **점화**, C는 콜당 27.4명으로 최고 효율이지만 시드가 필수인 **증폭**. 축별 최소 예산 몫을 보장한다. 발굴 항목(탐침)은 `(축, 대상, 산업군, 국가)` 단위로 워터마크·수확 이력·폐기 판정 상태를 갖는다. 깔때기는 항목 실행 → 중복 제거 → 프로필 조회 → 밴드 분류(밖은 EXCLUDED로 저장) → 게시물 조회 → 산업군 3축 동시 판정 → 확정. 종료 조건은 예산 콜 수와 목표 인원 중 먼저 도달하는 쪽이다.

**운영 배치**: harvest 크론 신설(KST 00:00 — collect 앞이라 신규 계정이 같은 밤에 게시물까지 수집돼 04:30 미러에 완전한 데이터로 진입), qualify·beauty 크론은 `"-"`로 내려 수동 백필·재판정 용도로만 남긴다. collect·reels는 자동 유지. 어드민 수동 트리거(discover·similar 포함)는 전부 보존하고 harvest 버튼만 추가한다. 판정이 발굴 안으로 들어오면서 DISCOVERED 적체가 구조적으로 사라져 07-24 유형(대량 유입→qualify 폭주→IG IP 차단) 재발 경로가 제거된다.

**핵심 실측치**: 밴드 조준 레버는 태그 규모가 아니라 top/recent 표면 선택(#메이크업 top 작성자 팔로워 중앙값 14,115 vs recent 1,180 — 12배, 표본 각 22명). 깔때기 수율은 1콜 → 작성자 27명 → 신규 22 → 밴드 통과 12 → 뷰티 인플루언서 2~3명으로, 뷰티 1명당 ≈14콜(한국 100명 ≈ 1,200~1,500콜 / $0.85~1.05). 실측 누적 940콜·$0.65.

**기각한 대안**(전부 채택 후보였다가 실측으로 반증 — 재시도 방지용, 상세는 설계 문서 §4): 팔로잉 교차(겹침률 91.9%·df≥8은 0명·df≥4의 48명 중 24개가 화장품 브랜드 공식계정), 위치 지오태그(뷰티 살롱 3곳 게시물 0건), 좋아요 프리필터(좋아요 500배 차이에 팔로워 중앙값 1.7배), 태그 규모 조준, `/v2/user/explore/businesses/by/id`, 무료 디렉토리 시드.

## 미결

- **뷰티 통과율 17~29%의 폭** — 살롱·시술자 계정을 인플루언서로 볼지의 경계가 정의돼 있지 않다. `beauty_company` 분류 기준 재확인이 필요하며, 이게 좁혀져야 비용 산정도 좁혀진다.
- **F&B 미판정 5,221건** — 기존 QUALIFIED의 F&B 판정이 전무하다(뷰티는 전량 완료). 이 트랙과 별개로 수동 백필이 필요하다.
- 카테고리 산업군의 행 기반(`influencer_category`) 전환은 네 번째 산업군 추가 전까지 유예 — 현재 `influencer`에 `beauty_*` 7컬럼 + `fnb_*` 6컬럼이 박혀 있어 산업군마다 컬럼이 늘어난다.
- 한국은 포화 시장이라 신규율이 시간에 따라 하락한다. 신규 시장(중동 등)에서는 축별 순위가 다를 수 있어 초기에는 축별 최소 몫을 넓게 잡아 탐색한다.
