# 인플루언서 분석 — 방향 결정 기록

- 작성일: 2026-07-09
- 상태: 진행 중 (하나씩 만들며 결정)

## 확정된 방향

1. **제품**: 외부 브랜드 고객이 **마이크로인플루언서를 찾기 위해** 쓰는 서비스.
   → 분석 단위는 콘텐츠가 아니라 **크리에이터**. 콘텐츠 랭킹은 크리에이터 평가의 증거.
2. **4기둥** (고객이 아파하는 문제 = 우리가 데이터로 답할 것):
   - **성과 증거**: 자칭이 아닌 측정된 카테고리 내 +3일 성과, 구간 대비 오버퍼폼
   - **진위 검증**: 가짜 팔로워/봇 댓글 탐지 — 댓글러 다양성·시간 집중도·뻔한 댓글 비율
   - **구매의도 오디언스**: 댓글 LLM 분류로 "어디서 사요" 류 구매 신호 비율 (🤖 이후 단계)
   - **스타일 매칭**: 영상 다운로드→세그멘테이션→훅/페이싱/구성 프로파일 (🎬 이후 단계, videoUrl은 이미 수집됨)
3. **크리에이터 딥다이브 수집(계정당 최근 N개 게시물) — 보류.** 일관성·팟탐지·스타일 프로파일은
   표본 부족 상태로 시작하고, 나중에 딥다이브 붙이면 자동 개선되는 구조로.
4. **종합 점수 — 보류.** 가중치 근거가 없으니 당분간 기둥별 지표를 그대로 보여준다.
5. **진행 방식: 하나씩.** 큰 계획 대신 만들고→보고→다음 결정.

## 단계

- **Step 1 (진행)**: 지금 DB로 가능한 성과+진위 기둥, 현실적 데모 데이터, 크리에이터 중심 대시보드
- Step 2 후보: 댓글 LLM 구매의도 분류
- Step 3 후보: 영상 세그멘테이션 스타일 분석
- 이후: 딥다이브 수집, 점수 체계 (전환 데이터 근거 생기면)

## 데이터 한계 (전제)

- 저장·공유·도달·팔로워 증감 없음 / +3일 단일 스냅샷 / 크리에이터당 표본 1~2개 (딥다이브 전)
