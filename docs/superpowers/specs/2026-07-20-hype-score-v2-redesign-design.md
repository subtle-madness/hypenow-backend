# hype_score v2 재설계 — 상위 뭉침 해소 + 연속 절대식

## 1. 배경·문제

v1(옵션 C, [PR #70](https://github.com/subtle-madness/hypenow-backend/pull/70))이 정규화 목표를 낮춰 중앙값은 19→39로 올렸으나, **하드캡(`min(x,1)`)** 구조가 그대로라 상위가 대량 포화됐다. 운영 분석 집합 실측:

- 서로 다른 지표(팔로워·참여율·댓글)를 가진 콘텐츠가 **91점에 20건 뭉침**. 최상위 변별이 사실상 신선도만 남음.
- **피드**는 축이 `axis²·fresh` 둘뿐이라 참여율 3.5%만 넘으면 axis=1.0 포화 → 참여율 10.9%짜리 대박 게시물이 4.0%짜리와 똑같이 91점. 상위권을 피드가 구조적으로 장악.
- **바이럴 릴스가 억눌림**: 조회수가 팔로워의 153배인 초대박 릴스가 도달 하드캡(3배)+참여율 하드캡 때문에 66점에 묻힘.

## 2. 결정 (사용자 확정, 2026-07-20)

1. **절대식 재설계** — 고정 산식, 시간 안정·비교 가능, 모집단 이동 시 주기 재보정. (상대 백분위 아님.)
2. **하드캡 제거 → 로그 무제한 축** — "도달·참여 높을수록 항상 점수 ↑".
3. **피드·릴스 동일 스케일 비교** — 타입별 앵커로 각 타입 출력 분포를 맞춰 대박 릴스·대박 피드가 비슷한 최상위 도달.
4. **도달:참여 = 1:1**.

## 3. 산식 v2

### 3.1 연속 축 (로그, 무제한 — 하드캡 없음)
```
릴스 도달  r  = ln(1 + views/(followers+1000))
릴스 참여  e  = ln(1 + ((likes + 3·comments)/views) / E0)          E0 = 0.02
피드 참여  ef = ln(1 + ((likes + 3·comments)/(followers+1000)) / F0)  F0 = 0.03
```

### 3.2 타입별 합성 Q
```
릴스: Q = wr·r + we·e        (wr = we = 1)
피드: Q = wf·ef              (wf = 1)
```

### 3.3 신선도
```
qf = Q · 0.5^(GREATEST(경과일,0)/halflife)     halflife = 14
```
경과일은 호출부가 계산해 넘김(v1과 동일: v_contents=now(), 스냅샷 뷰=captured_at 기준).

### 3.4 0~100 매핑 — 타입별 앵커 아핀(구간 선형)
타입별 **고정 앵커**(qf 값 → 점수). 앵커 사이 선형 보간, 결과 `[0,100]` 클램프.

| 타입 | p05→10 | p50→45 | p90→80 | p99→97 |
|---|---|---|---|---|
| 릴스 | 0.2405 | 0.9091 | 1.8845 | 2.9835 |
| 피드 | 0.0111 | 0.1398 | 0.6746 | 1.4890 |

- `qf ≤ p05` 구간: `10·qf/p05` (0으로 수렴).
- p99 초과: p90~p99 기울기를 이어 상승하되 `100` 클램프 — `LEAST(97 + 3·(qf−p99)/(p99−p90), 100)`.
- qf 값 앵커는 **운영 2026-07-20 분석 집합에서 산출**(§6 재보정). 출력 앵커(10/45/80/97)는 고정.

### 3.5 NULL 규칙 (v1 유지)
`likes` 또는 `comments` NULL → NULL. 릴스인데 `views` NULL → NULL. (피드 views 항상 NULL은 정상 — 피드 분기는 views 미참조.)

### 3.6 유지 결정
- **`comments×3`** 가중 유지. 알려진 엣지: 좋아요 3·댓글 1,409 같은 댓글 유도/경품이 과대평가될 수 있음 — 별도 판단 보류(이번 범위 밖).

## 4. 검증 (프로토타입 실측 — 운영 데이터 797건)

- **분포**: 전체 평균 44.1·중앙값 45·p75 61·p90 80·최대 99, **95↑ 12건뿐**(구: 91에 20건 뭉침 해소). 피드·릴스 거의 동일 분포(둘 다 p50 45·p90 80).
- **바이럴 정상화**: 153배 릴스 66→99, 51배 릴스 67→98.
- **피드 참여율대로 분리**: 참여율 17.6%→96 · 13.1%→92 · 10.7%→90 · 10.1%→89 (구 전부 91).
- **가중치 실험**: 참여 편중(1:2·1:3)은 "거의 안 퍼졌는데 소수 고참여"(도달 0.1배·참여율 49%)를 98점으로 띄우는 함정 확인 → 1:1 채택(참여 ≤ 도달).
